A Python program that writes a phone's last words at 1% battery, cut off mid-sentence by death itself.

Competition: [Famous Last Words at 1 Percent on make.fun](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4)

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line) to `/output/entry.txt`.
